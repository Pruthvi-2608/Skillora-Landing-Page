
# Skillora – Responsive Product Landing Page

## About the Project
Skillora is a UI/UX landing page concept for an online learning platform that helps students learn practical skills and prepare for their careers.

## Target Audience
College students aged 18–25 who want to learn UI/UX design, web development, and artificial intelligence.

## Design Choices
- Modern, minimal, and student-friendly interface
- Purple primary color: `#635BFF`
- Light background: `#F7F7FB`
- Dark typography: `#171923`
- Inter font family
- Auto Layout for structured and consistent spacing
- Desktop and mobile layouts

## Reusable Components
1. Card – Learn New Skills
2. Card – Build Real Projects
3. Card – Grow Your Career

## Shared Styles
- Primary / Purple: `#635BFF`
- Dark Text: `#171923`
- Background: `#F7F7FB`
- Secondary Text: `#626276`
- Typography: Inter
